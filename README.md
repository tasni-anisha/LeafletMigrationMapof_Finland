# Finland Municipality Migration Map

An interactive web map displaying migration data for Finnish municipalities.

## Features

- Interactive map built with Leaflet
- Municipality boundaries using GeoJSON
- OpenStreetMap background
- Municipality names displayed on hover
- Positive and negative migration data displayed on click
- Conditional municipality coloring based on migration data
- Data retrieved from Statistics Finland's PxWeb API

## Technologies

- HTML
- CSS
- JavaScript
- Leaflet.js
- GeoJSON
- PxWeb API
- OpenStreetMap

## Data Sources

Municipality geographic data and migration statistics are provided by Statistics Finland.
